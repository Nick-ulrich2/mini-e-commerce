# 🛒 Mini E-Commerce React

## Description
Application e-commerce minimaliste construite avec React.
Gestion de panier, filtres par catégorie et persistance des données.

## Stack
- React (Vite)
- JavaScript
- CSS
- LocalStorage

## Fonctionnalités
- Affichage de produits par carte
- Filtre par catégorie
- Ajout au panier avec gestion des quantités
- Suppression d'un article
- Vider le panier
- Persistance du panier (localStorage)

## Lancer le projet
```bash
git clone https://github.com/ton-pseudo/mini-ecommerce.git
cd mini-ecommerce
npm install
npm run dev
